## Reto adicional: LocalCultureAgent

Se incorporó un quinto agente especializado en cultura local.

Sus principales funciones son:

- Recomendar platos típicos del destino.
- Explicar costumbres y tradiciones locales.
- Sugerir frases útiles para el viajero.
- Promover el respeto por las diferencias culturales.

El agente está integrado al Travel Coordinator Agent.
